A view of validator activity

Validator Clock brings validator-round timing, election windows and recorded network data into one dashboard. It supports TON mainnet, Everscale mainnet and Tycho Testnet. The project is maintained by jouliene, with source code and development history available on GitHub.

The project is independently maintained. Network names identify the networks being observed; they do not imply endorsement by those networks.

Explore the dashboard

  • TON validators and elections — rounds, stakes and available TON validator data.
  • Everscale validators and elections — active rounds, EVER stakes and participation.
  • Tycho Testnet validators — observations from the test network.
  • Election guide — how to interpret the clock and its phases.
  • Data sources and methodology — calculations, freshness and limitations.

Report an issue or contribute

Use GitHub issues to report missing data, incorrect labels or interface problems. Include the network, observation time and round ID when relevant. The README explains how to run the project and the commit history records changes.

What's new in 2.5.5

Networks now have direct page URLs, recorded data readable without JavaScript, and linked explanations of election timing and calculations. Pages include descriptive metadata, with a sitemap to help search engines discover them.
