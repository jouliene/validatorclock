# Search indexing and referral measurement

Version 2.5.5 introduces English public pages:

- `/`: dashboard and snapshots of configured networks.
- `/ton/`, `/everscale/`, `/tycho-testnet/`: network dashboard and recorded validator table.
- `/methodology/`, `/guides/validator-elections/`, `/about/`: explanations and project information.

Network routes and the sitemap follow the configured chain list. Each public page
has an absolute canonical URL based on `tls.public_url`. Set this to the site's
public HTTPS origin, even when TLS terminates in a proxy. For local configurations
without a public URL, it falls back to the configured HTTP listen address.

HTML reads existing snapshots without RPC requests or map enrichment. Dates in
recorded HTML use UTC and label observation time. A snapshot is marked stale when
older than twice the refresh interval or after its recorded round ends. The live
clock continues to update separately, with dates in the browser's timezone.

`www` redirects to the configured canonical hostname in TLS mode. `/index.html`
redirects to `/`; known page paths without a trailing slash redirect to their
slash form. Query strings survive redirects but are excluded from canonicals and
sitemap URLs. Unknown paths retain HTTP 404 responses.

## Owner setup after deployment

These steps need the site owner's accounts; a code deployment does not complete them.

1. Add the domain property to Google Search Console. Verify ownership through the
   DNS TXT record generated by Search Console.
2. Add `https://validatorclock.xyz/` to Yandex Webmaster and complete its ownership
   verification, for example with the DNS TXT record it supplies.
3. Submit `https://validatorclock.xyz/sitemap.xml` in both services.
4. Inspect `/`, all three network pages and `/methodology/`. Check the fetched HTML,
   the selected canonical and whether the pages are eligible for indexing.
5. In Yandex Webmaster, inspect JavaScript rendering as well. Essential recorded
   content does not require JavaScript, but the live dashboard does.
6. Compare indexed pages, impressions, non-brand queries and clicks after enough
   observations have accumulated. Indexing, rankings and AI citations are not guaranteed.

## Robots and AI search

`/robots.txt` allows public crawling and points to the sitemap. No user-agent group
blocks Googlebot, YandexBot, OAI-SearchBot or PerplexityBot. Public assets and rendering
APIs stay accessible. The stats routes retain authentication; robots rules are not
access control. If a reverse proxy or firewall is introduced, check its bot rules
against each provider's documented IP ranges and user agents.

OAI-SearchBot is for ChatGPT search. GPTBot is for potential training use and has a
separate policy. This release does not change the existing unrestricted training
crawl policy. There is no special `llms.txt` requirement for Google AI search.

## Private referral report

`/stats` now includes **Entry visits · last 30 days**, backed by the authenticated
`/stats/traffic` endpoint. Attribution starts in 2.5.5; old history is not reconstructed.

A recorded entry is a `page_open` on a public page that starts a visit according to
the existing visitor-session rules. Subsequent page opens and heartbeats do not add
entry counts. If a visit starts with a heartbeat, or on the private stats page, it
has no public landing-page attribution. Consequently this report can be smaller
than the overall visit total.

The browser sends only the referrer origin, a bounded `utm_source` and the page path.
The server persists daily counts for a fixed set of source labels and known public
page paths, not raw referrer URLs, query strings or campaign names. Existing visitor
storage and its retention are unchanged. Daily source/page counts follow analytics
retention; the report covers today and the previous 29 UTC days.

Known sources include Google, Yandex, Bing, ChatGPT, Perplexity and Claude. Recognized
campaign labels take precedence over the referrer. Missing referrers become
`Direct or unknown`; unrecognized domains/campaigns are grouped as `Other referral
or campaign`. Referrer and campaign signals are client supplied and are not proof
of a source. The Google group cannot distinguish AI answers from ordinary search,
and omitted referrers mean this is not a complete measure of AI traffic.

## Release verification

Run the normal CI checks, then `scripts/browser-check.sh` against the newly built
binary. It exercises real network links, direct reloads, recorded content without
JavaScript and the methodology page in addition to the existing dashboard checks.

The share preview source is `public/brands/social-preview.svg`; its checked-in PNG
is served at `/social-preview.png`. To regenerate it with Chromium:

```sh
chromium --headless --disable-gpu --hide-scrollbars --window-size=1200,630 \
  --screenshot="$PWD/public/brands/social-preview.png" \
  "file://$PWD/public/brands/social-preview.svg"
```

No Search Console verification tokens, DNS records or external announcements are
included in this release.
